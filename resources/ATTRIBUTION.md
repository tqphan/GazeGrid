# Resource provenance

`icons.json` contains the Geometry paths used by the required keyboard pack, extracted from the original OptiKey `Resources/Icons/KeySymbols.xaml`. Copyright OPTIKEY LTD; retained under the original repository GPLv3 license. Eight pack names are explicit aliases to corresponding original icon names (see `symbol-aliases.json`). Geometry path data is unchanged.

`EnglishUS.dic` is copied unchanged from the original OptiKey `Dictionaries/EnglishUS.dic`; retain original project notices and verify third-party dictionary provenance before distribution. These resources are for the local development build; redistribution review remains part of packaging.
