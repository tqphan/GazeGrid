# Release versioning

Use major.minor.patch versions. Minor and patch components must each stay within
0–9; only the major component may exceed 9. Carry overflow into the preceding
component: 0.1.9 → 0.2.0, and 0.9.9 → 1.0.0.

Version 0.1.10 was already published before this rule was established. Leave that
release intact; the version sequence resumes at 0.2.0.
