# Wayland protocol source

`input-method-unstable-v1.xml` is vendored unchanged from wayland-protocols 1.47:
https://gitlab.freedesktop.org/wayland/wayland-protocols/-/blob/1.47/unstable/input-method/input-method-unstable-v1.xml

Its copyright and permissive license are embedded in the XML. CMake generates client bindings using the installed `wayland-scanner`. The implementation targets the v1 interfaces supported by KWin 6.8.
